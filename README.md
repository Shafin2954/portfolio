# Shafin Ahmed's Portfolio

Welcome to Shafin Ahmed's interactive portfolio, showcasing a blend of software engineering, data science, and creative projects. This portfolio is designed as a dynamic, terminal-inspired experience, allowing users to navigate through different sections like a file system.

## Features

- **Dynamic Backgrounds:** Ambient background shapes change color and position based on the current section.
- **Interactive Menu:** A vertical file-tree menu allows for easy navigation, with active sections highlighted.
- **Project Cards:** Detailed cards for applications, data science projects, and creative works.
- **Timeline:** An interactive timeline for exploring academic and professional background.
- **Cursor Spotlight:** A subtle spotlight effect follows the user's cursor.
- **Scroll Progress Bar:** Indicates reading progress within the portfolio.
- **Typing Animation:** Engaging hero text with a dynamic typing animation.
- **Responsive Design:** Optimized for various screen sizes, including a mobile-friendly hamburger menu.

## Technologies Used

- **HTML5:** Structure of the portfolio.
- **CSS3:** Styling, animations, and responsive design (including Tailwind CSS for utility classes).
- **JavaScript (ES6+):** Interactive elements, scroll logic, menu management, and dynamic content.
- **Intersection Observer API:** For detecting visible sections and updating UI elements accordingly.

## Setup & Usage

To view this portfolio locally:

1.  **Clone the repository:**
    ```bash
    git clone [repository-url]
    cd [repository-name]
    ```
2.  **Open `index.html`:**
    Simply open the `index.html` file in your web browser. No special server setup is required as it's a static site.

## Navigation

- **Vertical Menu (Desktop):** Click on items in the left sidebar to jump to sections.
- **Hamburger Menu (Mobile):** Tap the hamburger icon to open the navigation menu.
- **Scrolling:** Use the mouse wheel or scroll bar to move between main sections.
- **Horizontal Scroll (Works & Interests Sections):** Within the "Works" and "Interests" sections, scroll horizontally (or use mouse wheel) to browse through project cards.
- **Timeline:** Scroll horizontally within the "Background" section to view timeline nodes.
- **Keyboard:** Use `ArrowUp`/`ArrowDown`, `PageUp`/`PageDown`, `Home`/`End` keys to navigate.
