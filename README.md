
## Running locally

Static site — no build step needed.

```bash
# Option A: open directly
open index.html

# Option B: local server (avoids asset path quirks)
python -m http.server 8080
# then visit http://localhost:8080
```

## Generating domain illustrations

`tools/plot.py` uses matplotlib + scipy to render the three SVG-style PNGs used
in the hero domain cards. Toggle the `SHOW_*` flags at the top of the file, then
run:

```bash
python tools/plot.py        # outputs regression.png → rename to the target asset
```
